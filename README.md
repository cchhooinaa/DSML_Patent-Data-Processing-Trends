# DSML_Data-Processing-Evolution_A-Patent-Driven-LDA-Analysis

- 2024학년도 3학년 1학기 머신러닝기반데이터분석 팀 프로젝트 아카이빙 레포지토리

## Project Information
- 특허 데이터는 세상에서 존재하는 기술 정보의 90% 이상이 담겨 있고 국제적으로 표준화된 양질의 정보
- 다양한 미래 유망 기술 분석 방법론 중 '특허 정보'가 미래 기술을 분석하는 새로운 방법론으로 주목
- 주제
  - 특허 데이터를 활용한 디지털 데이터 처리 기술 트렌드 분석
- 목표
  - 디지털 데이터 처리 분야의 주요 기술 토픽 파악
  - 토픽별 기술 트렌드 파악
- 문제 정의
  - 특허 데이터를 활용해 데이터처리 기술 트렌드를 분석하는 LDA 모델
  - y = f(x)
  - f: LDA 토픽 모델링
  - y: 데이터처리 기술 트렌드
  - x: G06F(전기에 의한 디지털 데이터처리) 분야 특허 데이터

## 3. Data
> 특허정보활용서브시(KIPRIS Plus)에서 Open API 활용
- 수집기간: 20150101 ~ 20240501
- 분야: G06F(전기에 의한 디지털 데이터 처리)
- 수집 정보: '출원인', '출원일', '출원번호', '발명의 명칭', 'IPC 번호', '초록 내용' 등
- 데이터 크기: 87,223개

## 4. Pre-processing

### 4.1. 불필요한 컬럼 제거
- applicationDate(출원일), astrtCont(초록), inventionTitle(발명의 명칭) 컬럼을 제외하고 나머지 제거

### 4.2. 날짜 컬럼 형식 변경
- yyyy-mm-dd 형태의 applicationDate(출원일) 컬럼을 yyyy 형태로 변경(연도만 남김)

### 4.3. 자연어 처리(NLP)
- 텍스트 클리닝
  - 한글과 광백을 제외한 불필요한 문자 제거를 통해 텍스트 정제
  - 사용한 함수: clean_text(text)
  - 특허의 제목(title)과 초록(abstract)에 함수를 적용하여 정제된 텍스트 데이터 생성
 
- 토큰화 & 품사 태깅
  - 문장을 단어 단위로 분리하고, 각 단어의 품사 정보를 부착
  - 사용한 라이브러리: Okt
  - okt.pos()를 사용하여 텍스트를 토큰화하고 품사 태깅 수행
    - 명사(N), 동사(V), 형용사(A)로 시작하는 품사의 토큰만 추출
   
- 불용어 처리
  - 분석에 큰 의미를 갖지 않는 단어(불용어) 제거
    - 고빈도 단어 결과 참고하여 불용어 추가 선정
  - 도메인 특화된 불용어 사전 추가

  - 추출한 10개 토픽별 연도 분포
  - 토픽 클러스터링 및 네트워크 시각화
- 결론

  - '터피스크린 및 센서', '메모리 및 저장장치' 토픽 비중은 상대적으로 줄어드는 경향
